# Резултати: Laya срещу Jev

Суровите резултати зад таблицата в [README](../README.md), пуснати с
`evaluate.py`. Всеки пост се сравнява с началните 4 категории от
`seed.json`. При очаквана нова категория се мери само дали моделът е казал
"друга тема". Нови имена: BgGPT 3.0 4B през Ollama. Jev: `jev-latest` през
Vercel AI Gateway.

| Набор | Laya multilingual (CPU) | Jev |
|---|---|---|
| `test_posts.json`, 11 поста | 9/11 | 11/11 |
| `eval_posts.json`, 50 поста | 36/50 (39/50 с алтернативата) | 48/50 |
| от тях: съществуваща категория (28) | 24/28 | 28/28 |
| от тях: нова тема (22) | 12/22 | 20/22 |
| увереност >= 0,5: вярно | 27/33 | 48/50 |
| увереност < 0,5: вярно | 9/17 | няма такива |
| медиана на заявката (само избор, без BgGPT) | 200 ms | 380 ms |

Грешките на Jev: "Персеидите над Родопите" и "Птиците на Бургаските езера" ->
"Пътувания" (0,74 и 0,91). И двата поста наистина имат пътуване в себе си.

Първото пускане на Jev спря след 33 поста с `429 The upstream provider is
currently experiencing high demand`. SDK-то повтаря само 2 пъти по
подразбиране. С `RetryPolicy(max_retries=6, backoff_max=20)` тестът мина;
най-бавната заявка е 67s заради изчакването.

`jev-latest` е псевдоним и може да сочи нова версия.
